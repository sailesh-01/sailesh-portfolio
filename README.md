## 🚀 Deployment on Netlify

To deploy your portfolio from the command line, follow these exact steps:

1. **Install Netlify CLI globally:**
   ```bash
   npm install -g netlify-cli
   ```

2. **Login to your Netlify account:**
   ```bash
   netlify login
   ```

3. **Deploy to production:**
   ```bash
   netlify deploy --prod
   ```
   *Since `netlify.toml` specifies `publish = "."`, it will upload the files from this directory directly to your live site URL.*

### Folder Structure Overview

- `index.html`: Main markup, includes all SEO and structure.
- `css/style.css`: Contains CSS variables, glassmorphism utilities, and responsive design.
- `js/main.js`: Contains JavaScript for cursor manipulation, typing animations, theme toggles, and initialization for Particles.js & AOS.
- `netlify.toml`: Deployment definitions enabling one-click deployment behavior.
- `_redirects`: Setup routing correctly for single-page style deployments over SPA configs.
